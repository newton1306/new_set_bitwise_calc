# Set Bitwise Calculator (C Language)

โปรแกรมคำนวณเซตที่มีประสิทธิภาพสูง เขียนด้วยภาษา C โดยใช้เทคนิค **Bitwise Operations** ในการเก็บและประมวลผลข้อมูล ทำให้ทำงานได้รวดเร็วและประหยัดหน่วยความจำ รองรับการจัดการเซตผ่านหน้าจอ Console ที่ใช้งานง่าย (Clean UI)

## ✨ ฟีเจอร์หลัก (Features)

* **Fast Calculation:** คำนวณเซตด้วย Bitwise Logic (AND, OR, XOR, NOT) รวดเร็วมาก
* **User Friendly Interface:** หน้าตาโปรแกรมสะอาดตา มีระบบเมนู จัดระเบียบข้อความให้อ่านง่าย
* **File I/O:**
    * นำเข้าเซตจากไฟล์ (`.txt`) ได้ทีละหลายๆ เซต
    * บันทึกผลลัพธ์การคำนวณลงไฟล์ได้
* **Flexible Input:** รองรับการป้อนข้อมูลรูปแบบมาตรฐาน เช่น `A = {1, 2, 5, 7}`
* **Expandable:** โค้ดถูกเขียนแบบ Modular (แยกไฟล์ `.c`, `.h`) ง่ายต่อการนำไปพัฒนาต่อ

## 🛠️ การติดตั้งและคอมไพล์ (Installation)

โปรเจคนี้เขียนด้วยภาษา C มาตรฐาน (Standard C) จำเป็นต้องมี GCC Compiler ในการรัน

1.  **ดาวน์โหลดโค้ด** (หรือ Clone Repository)
2.  **เปิด Terminal** (cmd หรือ PowerShell) แล้วเข้าไปที่โฟลเดอร์โปรเจค
3.  **รันคำสั่งคอมไพล์:**
    ```bash
    gcc main.c set_calculator.c -o set_calc
    ```

**Windows:**
```cmd
set_calc.exe
