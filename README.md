# Set Bitwise Calculator PRO (C Language)

**Set Bitwise Calculator PRO** คือโปรแกรมคำนวณและจัดการเซตทางคณิตศาสตร์ที่มีประสิทธิภาพสูง พัฒนาด้วยภาษา **C (Standard C)** โดยใช้เทคนิค **Bitwise Operations** ในการจัดเก็บและประมวลผลข้อมูล ซึ่งช่วยลดการใช้หน่วยความจำและทำให้การคำนวณ (Union, Intersection, Difference) ทำได้รวดเร็วมาก

โปรแกรมมาพร้อมกับหน้าจอผู้ใช้งานแบบ Console (CLI) ที่สวยงาม ใช้งานง่าย รองรับการนำเข้าข้อมูลจากไฟล์ การคำนวณทางสถิติเบื้องต้น และการบันทึกผลลัพธ์

---

## ✨ ฟีเจอร์หลัก (Features)

* **⚡ Fast Bitwise Processing:** ใช้หลักการ *Bitwise Mapping* (1 บิต ต่อ 1 สมาชิก) ทำให้การคำนวณรวดเร็ว
* **➕ Set Operations:** รองรับการดำเนินการครบถ้วน:
    * Intersection (`&`)
    * Union (`|`)
    * Symmetric Difference (`^`)
    * Difference (`-`)
    * Complement (`~`)
* **📊 Statistics:** คำนวณค่าทางสถิติของเซตได้ทันที (**Mean** และ **Median**)
* **📂 File I/O:**
    * **Import:** อ่านข้อมูลเซตจำนวนมากจากไฟล์ `.txt` ได้ในครั้งเดียว
    * **Export:** บันทึกผลลัพธ์การคำนวณลงไฟล์ได้
* **⚙️ Configurable:** ปรับขนาดของเอกภพสัมพัทธ์ (Universal Set Size) ได้ง่ายผ่าน Header file

---

## ⚙️ การตั้งค่าก่อนใช้งาน (Configuration)

**⚠️ สำคัญ:** โดยค่าเริ่มต้น โปรแกรมรองรับตัวเลขสมาชิกตั้งแต่ **0 ถึง 7** (ขนาด 8 ตัว) เท่านั้น
หากต้องการใช้งานกับตัวเลขที่มากขึ้น (เช่น 0-31 หรือ 0-63) **ต้องแก้ไขค่า Config ก่อนคอมไพล์** ดังนี้:

1.  เปิดไฟล์ `set_calculator.h`
2.  ค้นหาบรรทัดที่มีคำว่า `#define UNIVERSAL_SET_SIZE`
3.  เปลี่ยนตัวเลข **8** เป็นค่าที่ต้องการ เช่น:
    ```c
    // set_calculator.h
    #define UNIVERSAL_SET_SIZE 32  // รองรับเลข 0 ถึง 31
    ```
4.  บันทึกไฟล์และทำการคอมไพล์ใหม่

## 🛠️ การติดตั้งและคอมไพล์ (Installation)

โปรแกรมนี้เขียนด้วยภาษา C มาตรฐาน จำเป็นต้องมี **GCC Compiler**

1.  **เปิด Terminal** หรือ Command Prompt แล้วไปยังโฟลเดอร์ที่เก็บไฟล์
2.  **พิมพ์คำสั่งคอมไพล์:**
    ```bash
    gcc main.c set_calculator.c -o set_calc
    ```
3.  **รันโปรแกรม:**
    * **Windows:** `set_calc.exe`
    * **Mac/Linux:** `./set_calc`

## 📖 คู่มือการใช้งานอย่างละเอียด (User Manual)

เมื่อรันโปรแกรมจะพบกับเมนูหลัก 6 หัวข้อ ดังนี้:

### 1. Input set (Keyboard) ⌨️
ใช้สำหรับป้อนข้อมูลเซตทีละ 1 เซตผ่านแป้นพิมพ์
* **รูปแบบที่ถูกต้อง:** `ชื่อเซต = {สมาชิก1, สมาชิก2, ...}`
* **ตัวอย่าง:**
    ```text
    A = {1, 2, 3, 5}
    MySet = {10, 20}
    ```
* *ข้อควรระวัง:* ชื่อเซตห้ามเว้นวรรค และตัวเลขต้องอยู่ในช่วง Universal Set ที่ตั้งค่าไว้

### 2. Input set (File) 📂
ใช้สำหรับอ่านเซตหลายๆ เซตจากไฟล์ Text (`.txt`) พร้อมกัน
* เตรียมไฟล์ `.txt` โดยเขียนเซตบรรทัดละ 1 เซต (รูปแบบเดียวกับการพิมพ์)
* เมื่อเลือกเมนูนี้ ให้พิมพ์ชื่อไฟล์ เช่น `sets.txt`
* โปรแกรมจะอ่านและบันทึกเซตทั้งหมดลงในหน่วยความจำทันที

### 3. Show all sets (Mean & Median) 👁️
แสดงรายชื่อเซตทั้งหมดที่มีอยู่ในระบบ พร้อมรายละเอียด:
* **สมาชิกในเซต:** แสดงตัวเลขสมาชิกทั้งหมด
* **ค่าเฉลี่ย (Mean):** ผลรวมสมาชิก หารด้วย จำนวนสมาชิก
* **มัธยฐาน (Median):** ค่ากึ่งกลางของสมาชิกในเซต
* *หากยังไม่มีเซต โปรแกรมจะแจ้งเตือน*

### 4. Calculate (Bitwise Ops) 🧮
โหมดคำนวณความสัมพันธ์ระหว่าง 2 เซต
1.  **ระบุชื่อเซตที่ 1:** (ต้องมีอยู่จริงในระบบ)
2.  **ระบุเครื่องหมาย (Operator):**
    * `&` : **Intersection** (สมาชิกที่มีร่วมกัน)
    * `|` : **Union** (รวมสมาชิกทั้งหมด)
    * `^` : **XOR/Symmetric Difference** (สมาชิกที่อยู่ใน A หรือ B แต่ไม่อยู่ในทั้งคู่)
    * `-` : **Difference** (สมาชิกที่อยู่ใน A แต่ไม่อยู่ใน B)
    * `~` : **Complement** (สมาชิกใน Universal Set ที่ไม่อยู่ใน A) *ใช้แค่เซตเดียว*
3.  **ระบุชื่อเซตที่ 2:** (กรณีไม่ใช่ Complement)
4.  **ผลลัพธ์:** โปรแกรมจะแสดงผลลัพธ์ และถามว่าต้องการบันทึกเป็นเซตใหม่หรือไม่ (Save result?)

### 5. Save results to file 💾
บันทึกเซตปัจจุบันทั้งหมด (รวมถึงเซตผลลัพธ์ที่กด Save ไว้) ลงไฟล์
* ระบุชื่อไฟล์ปลายทาง เช่น `output.txt`
* ไฟล์จะถูกสร้างขึ้นในโฟลเดอร์เดียวกับโปรแกรม

### 6. Exit 🚪
ออกจากโปรแกรม

## 📁 โครงสร้างไฟล์ (File Structure)

* `main.c`: ไฟล์หลักสำหรับแสดงผลเมนู (Menu Loop) และควบคุมการไหลของโปรแกรม
* `set_calculator.c`: ซอร์สโค้ดที่มีฟังก์ชันการทำงานทั้งหมด (Logic, Calculation, File I/O)
* `set_calculator.h`: เฮดเดอร์ไฟล์สำหรับประกาศฟังก์ชัน โครงสร้างข้อมูล (Struct) และค่า Config
* `sets.txt`: (ตัวอย่าง) ไฟล์สำหรับทดสอบการนำเข้าข้อมูล
* `README.md`: คู่มือการใช้งานนี้

## ❓ ปัญหาที่พบบ่อย (Troubleshooting)

**Q: พิมพ์เลข 8 หรือมากกว่า แล้วโปรแกรมไม่เก็บค่า?**
A: เพราะค่าเริ่มต้น `UNIVERSAL_SET_SIZE` คือ 8 (รับเลข 0-7) ให้แก้ค่านี้ในไฟล์ `.h` เป็น 32 หรือ 64 แล้วคอมไพล์ใหม่ (ดูหัวข้อการตั้งค่า)

**Q: เปิดไฟล์ไม่ได้ (Cannot open file)?**
A: ตรวจสอบว่าไฟล์ `.txt` อยู่ในโฟลเดอร์เดียวกับไฟล์ `.exe` หรือไม่ และชื่อไฟล์ถูกต้องพร้อมนามสกุล
